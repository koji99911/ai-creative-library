# 画像生成スキル

## 概要
AI画像生成ツールを使ってクライアント向け画像を制作するスキル。

## 使用ツール
- **Gemini Image Generation**: `generate_image` ツールで高品質画像生成
- **Canva / Figma**: 必要に応じてレイアウト調整

## プロンプト作成ガイドライン

### 基本構造
```
[被写体] + [スタイル] + [雰囲気] + [色調] + [技術指定]
```

### カテゴリ別プロンプト例

#### 美容サロン
```
A luxurious beauty salon interior. Warm lighting, pink and gold accents, 
fresh flowers. Professional photography style, shallow depth of field.
```

#### 飲食店
```
A beautifully plated [料理名] on a wooden table. Overhead shot, 
natural lighting, warm tones. Food photography style, appetizing.
```

#### ビジネス
```
A clean, professional business card/banner design. 
[色指定] color scheme, minimalist, modern typography.
```

## 品質チェックリスト
- [ ] 解像度: 最低 1080×1080px
- [ ] テキストの可読性
- [ ] ブランドカラーとの整合性
- [ ] SNSプラットフォーム別サイズ対応
- [ ] ロゴの適切な配置
