# 受注対応マニュアル — AI Creative Library

## 概要

本フォルダは、クライアントからの制作依頼を受けてから納品するまでのワークフローを管理します。

## フォルダ構成

```
client-orders/
├── README.md              ← このファイル
├── templates/             ← 注文書テンプレート
│   ├── image-order-template.md
│   ├── video-order-template.md
│   └── lp-order-template.md
├── skills/                ← AI制作スキル
│   ├── image-generation-skill.md
│   ├── video-render-skill.md
│   └── lp-creation-skill.md
└── orders/                ← 実際の案件（.gitignore対象）
    └── .gitkeep
```

## ワークフロー

### 1. 受注

1. クライアントからお問い合わせ受信
2. 適切な注文テンプレートをコピーして `orders/` に保存
3. ファイル名: `YYYYMMDD_[クライアント名]_[制作種別].md`

### 2. ヒアリング

1. テンプレートに沿ってヒアリング内容を記入
2. 参考画像・ロゴ・テキスト素材を `orders/[案件名]/assets/` に保存

### 3. 制作

1. `skills/` 内の該当スキルを参照して制作
2. 制作物は `orders/[案件名]/output/` に保存

### 4. 納品

1. クライアントに確認依頼
2. 修正があれば対応（修正回数は注文書に記載）
3. 最終版を `orders/[案件名]/final/` に保存
4. 納品完了後、注文書のステータスを「完了」に更新
